# Home 기능 규칙

- 홈 화면은 `docs/design-system.md` 기준으로 처음부터 다시 설계한다. 기존 섹션 구성·문구를 되살리지 않는다.
- 영어·한국어·일본어 콘텐츠의 키 구조를 항상 동일하게 유지한다.
- 지원 언어와 경로는 `src/constants/site.ts`, 번역 콘텐츠는 `constants/site-content.ts`에서 관리한다.
- 브랜드명·앱명과 자연스러운 영어 제품 라벨은 억지로 번역하지 않는다.
- 슬로건(`siteSlogan`)과 스튜디오 철학(`studioPhilosophy`)은 모든 언어에서 영어 원문을 쓰고, 소개 섹션에서만 뜻을 각 언어 설명으로 덧붙인다.
- 번역투보다 각 언어 사용자가 실제로 읽기 자연스러운 문장을 우선한다.
